## 🌟 Описание проекта

**Smart Home & Family Task Hub** — это домашний органайзер, созданный для объединения всех бытовых задач семьи в едином аккуратном интерфейсе. 

Больше никаких потерянных бумажных списков на холодильнике или забытых просьб в бесконечных чатах мессенджеров:
- 🛒 **Синхронизированный список покупок**:
  - Быстрое добавление продуктов и товаров для дома с категориями (Овощи, Молочное, Бытовая химия, Аптека).
  - Удобная отметка купленного в один тап прямо у магазинной полки со смартфона.
  - Очистка завершенных покупок одной кнопкой.
- 📋 **Канбан-доска семейных поручений**:
  - Распределение задач по исполнителям (🌸 Мама, 🛠 Папа, 💻 Я, 🏡 Вся семья).
  - Приоритеты срочности (Высокий, Средний, Обычный) и дедлайны.
  - Три статуса: «К выполнению», «В процессе», «Сделано ✅».
- 📊 **Домашний дашборд продуктивности**:
  - Процент закрытых дел за день, индикатор статуса сервера и быстрый учет прогресса.

## 🛠 Стек технологий

- **Backend**: Python 3.11+, FastAPI, Uvicorn, SQLite3 (транзакционная целостность, отсутствие внешних платных СУБД)
- **Frontend**: HTML5, Tailwind CSS, Vanilla JS (быстрый отклик на слабых смартфонах и планшетах)
- **Адаптивность**: Полная поддержка мобильных экранов (iOS Safari, Android Chrome)

## 🚀 Быстрый запуск

### Запуск в 1 клик (Windows):
Дважды щелкните по:
```bash
start.bat
```
*(Сервер запустится и откроет страницу `http://localhost:8003`)*.

### Запуск вручную:
```bash
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8003
```
Для открытия с телефонов семьи подключитесь к домашнему Wi-Fi и перейдите по адресу:
`http://<IP_ВАШЕГО_ПК>:8003`

## 🖥 Зачем этому проекту нужен выделенный сервер 24/7?

Семейный органайзер раскрывает 100% своей ценности только при постоянной работе без выключения:

1. **Мгновенный доступ из супермаркета**:
   - Когда мама или папа заходят в магазин, домашний компьютер может быть выключен или находиться в спящем режиме. Выделенный сервер 24/7 гарантирует, что список покупок всегда доступен онлайн.
2. **Безопасность и конфиденциальность семейных данных**:
   - Никакие коммерческие корпорации не имеют доступа к вашим планам, расписанию и покупкам. База данных хранится исключительно на локальном домашнем диске.
3. **Telegram-уведомления и напоминания по расписанию**:
   - Серверный планировщик задач (cron) может каждое утро в 9:00 присылать родителям в Telegram сводку задач на день или напоминать о необходимости полить цветы и купить продукты.
